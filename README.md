# Minecraft AutoBot — publiczne aktualizacje

To repozytorium udostępnia gotowe pliki `.jar` moda Minecraft AutoBot dla Fabric 1.21.11.

- `latest.json` wskazuje aktualną wersję, rozmiar i sumę SHA-256.
- `releases/` zawiera pliki instalacyjne JAR.
- Kod źródłowy jest przechowywany osobno w prywatnym repozytorium autora.

Instalator Minecraft AutoBot sprawdza zgodność pliku i instaluje go po zamknięciu gry.
Nie umieszczaj w tym repozytorium tokenów, haseł ani prywatnych danych.
